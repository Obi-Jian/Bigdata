# bigdata_0

Questo repository contiene un progetto universitario per l'analisi di dati su dataset reperiti online. Il progetto utilizza strumenti di analisi dati avanzati per esplorare e generare insight significativi dai dataset.

## Struttura del progetto
La struttura del repository include:
- Script e notebook per l'analisi dati (principalmente in Jupyter Notebook).
- Dataset utilizzati per l'analisi.

## Requisiti
Per eseguire i notebook, assicurarsi di avere installato:
- Python 3.x
- Le seguenti librerie principali:
  - Pandas
  - NumPy
  - Matplotlib
  - SciKit-learn (se utilizzata)

Utilizzare il seguente comando per installare le dipendenze:
```bash
pip install -r requirements.txt
```

## Dataset
I dataset utilizzati in questo progetto sono stati trovati online e sono inclusi nella directory appropriata di questo repository.

## Utilizzo
1. Clonare il repository:
   ```bash
git clone https://github.com/Obi-Jian/bigdata_0.git
   ```
2. Navigare nella directory del progetto:
   ```bash
cd bigdata_0
   ```
3. Aprire ed eseguire i notebook Jupyter per esaminare l'analisi dei dataset.
